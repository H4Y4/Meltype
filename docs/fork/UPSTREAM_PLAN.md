# 上流 (yksr-melt/Meltype) へ提案する計画

H4Y4 フォーク (`integration/mac-parity-v6`、リリース `v1.2.2-pre.1-mac-parity-v6.2`) の変更を、上流に 1 件ずつ提案するためのメモ。
**まだ実行していない。** 進めたら「状態」を更新する。

## 進め方

- 1 件の PR につき、上流の `main` から新しいブランチを切り、下の表のコミットを**順番どおりに cherry-pick** する
  ```sh
  git fetch upstream
  git switch -c <ブランチ名> upstream/main
  git cherry-pick <コミット> <コミット> ...
  ```
- フォークのブランチ (`integration/mac-parity-v5`・`integration/mac-parity-v6`・`feat/*`・`fix/*`) は、cherry-pick の元として**消さずに残す**
- 統合ブランチには本家の main を取り込んだマージのコミットがあるので、マージのコミットは cherry-pick しない (表には載せていない)
- 上流の main は先に進んでいるので、cherry-pick で衝突したら上流の書き方に合わせて直す。直したら Windows (`dotnet run --project src/Meltype.Core.Tests`・`src/Meltype.Tests`、`native/tip/build.ps1`) と、Mac は CI の `mac` で確かめる
- 「依存」の PR が上流に入るまでは、その PR を出さない (または依存のコミットも一緒に載せて、そう書く)
