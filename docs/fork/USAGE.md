# この fork (H4Y4/Meltype) で足した操作と設定

本家の使い方は [docs/USAGE.md](../USAGE.md)。ここには、この fork だけにあるもの (Windows・Mac・Linux 共通) を書きます。
Mac だけのものは [MAC.md](MAC.md)。本家へは 1 件ずつ提案する予定です ([UPSTREAM_PLAN.md](UPSTREAM_PLAN.md))。

## キー操作

| キー | 動き |
| --- | --- |
| PageDown (変換中) | 候補の一覧を次のページ (9 個ずつ) に送り、そのページの先頭の候補を選ぶ。最後のページの次は最初のページに戻る。1 ページに収まるときは何も動かない。Mac では Shift+↓ も同じ (Windows・Linux の Shift+↓ は今までどおり 1 つずつ) |
| PageUp (変換中) | 前のページの先頭の候補を選ぶ。最初のページの前は最後のページ。Mac では Shift+↑ も同じ |
| F8 | 半角カタカナ。全角の記号・英数字・空白も半角にする (aiueo → ｱｲｳｴｵ、gappa → ｶﾞｯﾊﾟ) |

- z + `h` `j` `k` `l` で矢印 (vi のカーソル移動と同じ向き): `zh` → ←、`zj` → ↓、`zk` → ↑、`zl` → →。小文字で打ったときだけです (`Zl` は矢印にしない)。`puzzle` `dazzle` のような英単語の途中や、読めなかった英字の後ろ (`githubzl`) は矢印にしません。ユーザーのローマ字の表に同じ綴りがあれば、そちらを使います。設定「z + 記号・hjkl で記号・矢印を入れる」を OFF にすると矢印にしません
  - 本家 v1.4 の区切り方に移ってから、z で始まる英単語 (`zlib` `zhang`) は矢印になります (前の版では英字に戻していました。直すかは検討中)

## 入力中の Ctrl キー (macOS 風)

本家の設定「Control キーの割り当て」を「macOS 風」(`config.json` の `"ControlKeys": "Mac"`) にしたときは、この fork の Mac 式の表を使います。Meltype IME (Windows) でも、動作モードを変えずに同じに効きます。

| キー (入力中) | 動き |
| --- | --- |
| Ctrl+J / K / L / ; / : / ' | Ctrl+J ひらがな (F6) / Ctrl+K カタカナ (F7) / Ctrl+L 全角英字 (F9) / Ctrl+; ・Ctrl+: ・Ctrl+' 半角英字 (F10。macOS の既定の「ローマ字に変換」と同じ)。Ctrl+: は Shift を押さずに打つ : のキー (JIS 配列) だけ |
| Ctrl+N / P / F / B | 次の候補 (↓) / 前の候補 (↑) / 次の文節 (→) / 前の文節 (←)。変換前 (かな) でも同じ。英語と判定した語や F9 / F10 で英字にした後は割り当てなし (確定してから Ctrl+キーをアプリに渡す) |
| Ctrl+W / O / I | 選んでいる文節を伸ばす (Shift+→) / 伸ばす / 縮める (Shift+←) |
| Ctrl+V / R | 候補の次 / 前のページ (変換中だけ) |
| Ctrl+M | 確定 (Enter と同じ。改行は入れない) |
| Ctrl+H | BackSpace と同じ (どの割り当てでも) |

- 本家の macOS 風の Ctrl+D・Ctrl+A / E は、変換中の文字の中でそれを受け取る処理がまだ無いので割り当てていません
- 前の版の fork の `"ControlKeys": "Mac"` / `"Atok"` は、読み込むときに「macOS 風」/「標準」として読みます
- **キーの割り当てを変えるソフトと一緒に使う (AutoHotkey など)**: Meltype は、入力中 (変換ボックス・Meltype IME の変換中) の間だけ、名前付きのイベント `Local\Meltype.Composing` をシグナル状態にします。Emacs 風の割り当てなど、Ctrl+キーを別のキーに変えるソフトでは、入力中だけ Meltype の割り当て (Mac 式の Ctrl+K カタカナなど) を優先できます。AutoHotkey v2 の例:

  ```ahk
  MeltypeComposing() {
      static handle := 0
      if (!handle)
          handle := DllCall("OpenEvent", "UInt", 0x00100000, "Int", 0, "Str", "Local\Meltype.Composing", "Ptr")
      return handle && DllCall("WaitForSingleObject", "Ptr", handle, "UInt", 0) = 0
  }
  #HotIf not MeltypeComposing()
  ^k::Send "{ShiftDown}{End}{ShiftUp}^x"  ; 入力していないときだけ行末まで切り取る
  #HotIf
  ```

## 記号・スペースの設定 (設定の「記号・スペース」)

- **全角にする記号 / 半角にする記号**: 「全角にする記号」に書いた記号はいつも全角に、「半角にする記号」に書いた記号はいつも半角 (打ったまま) にします。たとえば「全角にする記号」に `()`、「半角にする記号」に `<>` と書くと、`(` `)` は全角の（ ）に (Mac の日本語入力と同じ)、`<` `>` は日本語の中でも半角になります。`[]` を「半角にする記号」に書くと、「」ではなく `[` `]` になります。書いた記号は、英単語を囲むとき (`人工知能（AI）`) も、英文の続きでもその幅です。もう一方の幅にしたいときは、Space で変換して候補から選びます。両方に書いた記号は半角にします。`-` `,` `.` `/` は書いても変わりません。URL の中、パスの中の括弧 (`app/(auth)/login`)、英単語の中の記号 (`don't`) は、書いてあっても打ったままです。Mac・Linux 版では `config.json` の `"FullWidthSymbols": "()"`、`"HalfWidthSymbols": "<>"` のように書きます
- **- を長音 (ー) にするのは、かなの後ろだけ**: ON にすると、「ー」にするのはかなのすぐ後ろ (`らーめん`) だけになり、打ち始め・記号や英字の後ろでは半角の `-` のままです (`->`、`--`)。`config.json` では `"LongVowelOnlyAfterKana": true`
- **記号だけ打って Space で、確定して空白**: ON にすると、幅を決めた記号だけを打って Space を押したとき、候補を開かずに確定して空白を入れます。Markdown の記号 (`#` `-` `*` `+` `>`) だけのときは、この設定に関係なく打った半角 + 空白で確定します (本家の動作)。`config.json` では `"SpaceCommitsSymbols": true`
- **¥ キーで入力する文字**: 「\ (バックスラッシュ)」にすると、日本語の中で打った `\` (JIS キーボードの ¥ キー) を全角の ￥ にせず、半角の `\` のまま入れます (Mac の日本語入力の「"¥" キーで入力する文字」と同じ)。Mac の JIS 配列の ¥ キーも `\` になり、英数のときにも効きます。`config.json` では `"YenKey": "Backslash"`
- 設定を書き換えると、開いたままの入力欄にも 1 秒ほどで効きます。新しく入力欄を選んだときは、すぐに効きます

## 日付の候補

- 「きのう」「おととい」「あした」「あす」「あさって」「しあさって」: 「きょう」と同じ形で、その日の日付 (「きのう」なら 2026年10月8日 / 2026/10/08 / 木曜日 など)
- 「こんげつ」「せんげつ」「らいげつ」: 2026年10月 / 10月 / 2026/10 / 2026-10
- 「ことし」「きょねん」「らいねん」: 2026年 / 2026
- 日付の候補は、選んで確定しても学習しません (全角数字・漢数字の日付も)

## アプリ (Windows)

- どのアプリでも同じ動作にしたいときは、設定の「アプリの種類で動作を変える」を OFF にします。種類「コード」と独自の種類を使わず、すべて一般として扱います (アプリ別設定の中身は残ります。アプリごとの OFF と種類「ゲーム」はそのまま効きます)
- アプリや環境でまったく動作を変えたくないときは、設定の「どのアプリでも同じ入力にする」を ON にします。アプリ別設定、「全画面アプリでは無効」「ゲームでは止める」をまとめて使わず、ターミナル (Claude Code などの CLI) や全画面のアプリでも、ほかのアプリと同じように入力欄で日本語を判定します

## 設定のファイル (Windows ⇔ Mac・別の PC)

トレイの右クリックの「設定のファイル」→「設定を書き出す...」で、今の設定を `*.meltype-profile.json` にします。別の PC や Mac の Meltype で「設定を読み込む」を選ぶと、同じ設定にできます (Mac は入力メニューの「設定を読み込む…」)。読み込んだ設定は新しいプロファイルになり、前の設定もプロファイルとして残ります。Meltype の ON/OFF・動作モード・ログ・更新など PC ごとの項目は書き出さず、読み込んでも変えません。学習データ・ユーザー辞書は入りません。

## 調べるとき用のログ (Meltype IME)

設定でログを ON にすると、Meltype IME (Windows) は tip.log に、入力欄が変わってから最初に届いたキー・TSF がキーを IME に渡すかの変わり目・黙って通したキーの理由を書きます (どのキーかは書きません)。Meltype.exe は、コードの行として英字のまま通したときに meltype.log に書きます。「Meltype IME が有効なのに英字のまま入る」ときに、キーが IME に届いているかを見分けるためのものです。
